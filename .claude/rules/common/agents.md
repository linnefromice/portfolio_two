# エージェントオーケストレーション

## 利用可能なエージェント

| エージェント | 目的 | 使用タイミング |
|-------------|------|----------------|
| planner | 実装計画 | 複雑な機能、リファクタリング |
| architect | フロントエンド設計 | アーキテクチャ決定 |
| tdd-guide | テスト駆動開発 | 新機能、バグ修正 |
| code-reviewer | コードレビュー | コードを書いた後 |
| build-error-resolver | ビルドエラー修正 | ビルド失敗時 |
| refactor-cleaner | デッドコードクリーンアップ | コード保守 |
| doc-updater | ドキュメント更新 | ドキュメント更新時 |

## 即時エージェント使用

ユーザーの指示を待たずに使用:
1. 複雑な機能リクエスト → **planner** エージェント
2. コードを書いた/修正した直後 → **code-reviewer** エージェント
3. ビルド失敗時 → **build-error-resolver** エージェント

## 並列タスク実行

独立した操作には常に並列 Task 実行を使用。
