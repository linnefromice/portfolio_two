# テスト要件

**注意**: 現在テストフレームワーク未導入。導入時はVitestを推奨。

## テストタイプ

1. **ユニットテスト**（Vitest） - 個々の関数、ユーティリティ
2. **コンポーネントテスト**（Vitest + React Testing Library） - Reactコンポーネント
3. **E2Eテスト**（Playwright） - クリティカルなユーザーフロー

## テスト駆動開発

推奨ワークフロー:
1. まずテストを書く（RED）
2. テストを実行 - 失敗するはず
3. 最小限の実装を書く（GREEN）
4. テストを実行 - パスするはず
5. リファクタリング（IMPROVE）
