# Verifyコマンド

現在のコードベース状態に対して包括的な検証を実行。

## 手順

この正確な順序で検証を実行:

1. **型チェック**
   - `pnpm compile` を実行
   - すべてのエラーをファイル:行で報告

2. **ビルドチェック**
   - `pnpm build` を実行
   - 失敗した場合、エラーを報告して停止

3. **Lintチェック**
   - `pnpm lint` を実行
   - 警告とエラーを報告

4. **console.log監査**
   - src/ディレクトリ内のconsole.logを検索
   - 場所を報告

5. **Gitステータス**
   - コミットされていない変更を表示
   - 前回のコミット以降の変更ファイルを表示

## 出力

簡潔な検証レポートを生成:

```
VERIFICATION: [PASS/FAIL]

型:        [OK/Xエラー]
ビルド:    [OK/FAIL]
Lint:      [OK/X問題]
ログ:      [OK/X件console.log]

PR準備完了: [YES/NO]
```

クリティカルな問題がある場合は、修正提案とともにリストアップ。

## 引数

$ARGUMENTSの選択肢:
- `quick` - 型チェック + ビルドのみ
- `full` - すべてのチェック（デフォルト）
- `pre-commit` - コミットに関連するチェック
